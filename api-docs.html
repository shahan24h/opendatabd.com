Overview

The OpenDataBD REST API provides programmatic access to Bangladesh's largest open data catalog. All endpoints return JSON. Most read endpoints require no authentication. Submitting datasets and generating API keys uses the endpoints below.

Base URL: http://localhost:3000/api    Format: JSON    Auth: optional API key

Endpoints

List Datasets

GET /api/datasets Search and filter all datasets
ParameterTypeDescription
q optionalstringFull-text search across title, description, tags, source
category optionalstringFilter by category slug (e.g. health, agriculture)
format optionalstringCSV, JSON, API, XLS, GEO
division optionalstringDhaka, Chittagong, nationwide, etc.
license optionalstringCC0, CC-BY 4.0, Govt. Open
sort optionalstringnewest (default), popular, downloads, az
page optionalintegerPage number (default: 1)
limit optionalintegerResults per page (default: 20, max: 100)
# Example: search health datasets in Dhaka
GET /api/datasets?category=health&division=Dhaka&sort=popular

Code Examples

Python

import requests

# List health datasets
resp = requests.get("http://localhost:3000/api/datasets", params={
    "category": "health",
    "format": "CSV",
    "sort": "popular"
})
datasets = resp.json()["datasets"]
for d in datasets:
    print(d["title"], d["source"])

JavaScript (fetch)

const res = await fetch('http://localhost:3000/api/datasets?q=flood&sort=newest');
const { datasets, total } = await res.json();
console.log(`Found ${total} datasets`);
datasets.forEach(d => console.log(d.title));

curl

# Search for all CSV datasets
curl "http://localhost:3000/api/datasets?format=CSV&sort=popular"

# Get a single dataset
curl "http://localhost:3000/api/datasets/1"

# Submit a dataset
curl -X POST http://localhost:3000/api/datasets \
  -H "Content-Type: application/json" \
  -d '{"title":"My Dataset","category":"health","format":"CSV","source":"dghs.gov.bd","description":"..."}'

Data License

OpenDataBD aggregates data from multiple sources under various open licenses. Each dataset carries its own license field. Most common licenses:

  • CC0 — Public domain. No restrictions. Use freely.
  • CC-BY 4.0 — Credit the source. Commercial use allowed.
  • Govt. Open — Bangladesh Government Open Data License. Free for non-commercial use; credit required.
  • CC-BY-SA 4.0 — Credit + share alike. Derivatives must use the same license.
Always verify the license of each individual dataset before publication. OpenDataBD provides data in good faith but cannot guarantee completeness or accuracy of government sources.
